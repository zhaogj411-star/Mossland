# 代码索引

Mossland 当前包含 agent harness 和音乐多任务 codec 训练代码。

## 仓库根部

- `AGENTS.md`：仓库代理规则。
- `.codex/hooks.json`：Codex 生命周期 hook 配置；命令指向 `agent-code/scripts/codex-hook.sh`。
- `agent-code/`：完全由机器管理的 agent harness 代码根目录。
- `agent-code/scripts/agent/`：显式 preflight、impact 和验证命令。
- `agent-code/scripts/codex-hook.sh`：生命周期提醒 hook。
- `agent-code/tests/agent/`：agent harness 测试。
- `bash/eval_mossland_codec_checkpoint.sh`：给定 Mossland codec Lightning checkpoint 后直接启动 MusicCaps-HF full-clip reconstruction 评测流水线；无参数默认评测 `logs/mossland-codec/runs/2026-06-12_12-46-36/checkpoints/last.ckpt/last.ckpt`。脚本会导出 EMA/raw checkpoint 目录，用 `codec_reconstruct_infer.py` 调 `scripts/mossland-codec/inference.py` 的 `EncoderDecoder.encode()` + `decode(mode="parallel")` 做整段重建，并串起 CLAP、VGGish、ViSQOL；输出在 `scripts/mossland-codec/eval_benchmark/runs/<RUN_NAME>/`，日志在 `scripts/mossland-codec/eval_benchmark/logs/<RUN_NAME>.log`。
- `bash/push_oss_files.sh`、`bash/pull_oss_files.sh`：使用 `scripts/tools/oss_tools/bin/rclone` 和本机 `rclone.conf` 在本地 `NETEASE_SPIDER` 与 OSS `qz_oss2:embodied-multimodality/public/Sonata/data/raw/NETEASE_SPIDER` 之间同步；支持命令行参数或 `LOCAL_SRC/OSS_DST/OSS_SRC/LOCAL_DST/TRANSFERS/CHECKERS` 覆盖。
- `bash/prepare_seperation/node0.sh` 到 `node3.sh`：4 台机器多机多卡 separation 预处理启动脚本；每台机器 8 卡，总 `--num-shards 32`，每张 GPU 一个独立进程，使用全局 `--shard-id`，日志写入 `NETEASE_SPIDER_SEPERATION_NEW/_logs/prepare_separation_multinode/`。
- `scripts/train.py`：Hydra/Lightning 训练入口。
- `scripts/codicodec/`：保留的 CoDiCodec 独立参考实现和原始实验入口依赖代码；`scripts/mossland-codec/` 不 import 它。
- `scripts/mossland-codec/`：Mossland 多任务 codec 自包含实现，包含 `MosslandCodecTransformer`、音频表示、consistency decoder、训练 wrapper、任务适配层和最小训练基类；模型负责 `prepare_audio_batch()` 与 `generate_waveform()`，decoder conditioning 只使用 sigma embedding 加 5 个 `task_id` embedding；`tasks.TASK_NAMES` 是主 codec 默认 5 任务，`tasks.SUPPORTED_TASK_NAMES` 额外包含 `separate_drums/separate_bass/separate_other` 以支持 MUSDB 四 stem 数据构造和评测，但这些扩展任务不进入主 codec 默认 task embedding；wrapper 只消费 `src/target/task_id` 标准任务 payload 并执行训练循环；`random_mix_prob` 只允许 reconstruction-only batch 使用，避免破坏 separation、SR、mono-to-stereo 的 `src/target` 对齐；demo callback 每个样本同时保存 quantized 与 continuous 两份 `src/target/generated` 对比音频；不集成完整 `scripts.music2latent`，不保留 `hparams.py` 或 `hparams_inference.py`。
- `scripts/mossland-codec/eval_benchmark/`：Mossland 五任务评估 pipeline。`build_manifest.py` 从 prepared `mixture/vocals/accompaniment` 目录生成固定 JSONL manifest；`build_audio_task_manifest.py` 从已有单音频 manifest 派生 reconstruction、super-resolution bucket 和 mono-to-stereo 多 seed 样本；`download_public_dataset.py` 按 `public_datasets.json` 下载 MUSDB18-HQ/MUSDB18，支持 `--no-proxy`、`--head`、`.part` - `scripts/configs/experiment/mossland-codec.yaml`：Mossland 多任务 codec 训练配置，命令为 `python scripts/train.py experiment=mossland-codec`；`model:` 节显式传入模型、音频表示和噪声调度参数，当前容量约 494M 参数且保持压缩相关 `hop/fac/spec_length/num_latents/fsq_levels/frontend_freq_downsample_list` 不变；dataset 直接使用 `PreparedSeparationDataset` 读取 `NETEASE_SPIDER_SEPERATION_NEW` prepared folder，当前 `crops_per_file=16`、`train_batch_size=1`，一次 mp3 解码提供 16 个 crop、每个 crop 独立随机任务，展平后有效 batch 为 16；`length=10000000` 固定逻辑 epoch 长度，真实条目用当前 `item_dirs` 取余；wrapper 的 `index_data_every_step=null` 表示训练中不重建索引，改成正整数后会在 `on_train_batch_end()` 按 `trainer.global_step` 调用底层 dataset 的 `rebuild_index()`；`max_duration_seconds=300` 会在选中单条 item 后用 `ffprobe` 在 mp3 decode 前 lazy 过滤大于等于 5 分钟的条目；当前 `num_workers=6,prefetch_factor=2`，需要继续观察多卡首批预取的共享存储压力；任务列表、权重和 `low_sample_rate` 只配置在 `MosslandTaskDataset`，wrapper 不再重复维护这些参数；`super_resolution.low_sample_rate=[8000,40000]` 表示从固定 fast audio SR bucket 采样，不在 DataLoader 热路径采任意整数 rate。
- `scripts/configs/experiment/codicodec-paper-repro.yaml`：用 `scripts/mossland-codec` 搭建的 CoDiCodec 论文风格 reconstruction 复现配置。它把模型调回论文口径 `dim=512`、`num_layers=12`、`cond_channels=512`、`frontend_multipliers_list=[1,2,4,8]`、`fsq_dropout_prob=0.75`、`learning_rate=1e-4`、单任务 `reconstruct`、`random_mix_prob=0.5`。按用户要求，当前数据目录为 `/inspire/sj-ssd3/project/embodied-multimodality/public/Sonata/data/raw/NETEASE_SPIDER`；128 卡训练口径为每卡 effective batch 16、全局 batch 2048、`max_steps/lr_schedule_total_steps/consistency_step_total_steps=20000`、`lr_warmup_steps=100`，约 4096 万样本，接近论文单卡 batch 20 跑 200 万步的 4000 万样本。该配置使用 `strategy=ddp_find_unused_parameters_true`，因为 reconstruction-only 路径会让部分 task/conditioning 参数不参与每步 loss；`SampleDataset.index_file` 指向 `tmp/codicodec-paper-repro/netease_spider_audio.index.list`，首个进程用 `.lock` 构建共享持久文件列表，其余 rank 等待后读取，避免 128 rank 同时递归扫描 700 万级 raw 音频。该配置仍不是 bit-identical 官方复现，因为数据不是论文 MTG-Jamendo/DNS4/M4Singer 混合，且 CoDiCodec 官方最终训练分支未公开在 `SonyCSLParis/music2latent`。
- `scripts/configs/experiment/codicodec-paper-repro-a2a.yaml`：Mossland audio-to-audio 多任务训练配置，命令为 `python -m scripts.train experiment=codicodec-paper-repro-a2a`；模型目标是 `scripts.mossland-a2a.models.MosslandA2ATransformer`，wrapper 是 `scripts.mossland-a2a.wrapper.MosslandA2ATrainingWrapper`。它复用 Mossland STFT representation、frontend、`Transformer_Diffusion`、task embedding 和 consistency loss；A2A 模块内显式声明自己的 6 个任务，不借用主 codec 的 5-task `TASK_NAMES`；source 侧使用非压缩 encoder，把 source frontend tokens 原样计数变换成 conditioning tokens，不使用 learned latent query、extra latents 或 FSQ，也不再把 source 频谱直接 concat 到 decoder input。传给 decoder down path 的 multiscale features 由 encoded source tokens 经过 `frontend_pre_decoder_up(..., skip_output_layer=True)` 生成，保持与 decoder frontend stage 对齐。`MosslandTaskRoutedDataset` 在同一训练流里把 `separate_vocals/separate_drums/separate_bass/separate_other` 路由到 MUSDB18-HQ wav stem 树，把 `super_resolution` 和 `mono_to_stereo` 路由到 `/inspire/sj-ssd3/project/embodied-multimodality/public/Sonata/data/raw/NETEASE_SPIDER` 原始音频，并把底层异构 metadata 规整为固定 `info` schema 供 default collate 使用。
- `scripts/data/`：音频数据集和 DataModule 工具。
- `scripts/data/prepare_separation.py`：按本地 Kimberley Mel-Band RoFormer vocal model config/ckpt 离线生成 `mixture.mp3/vocals.mp3/accompaniment.mp3` 分离结果；默认读取 `checkpoints/mel-band-roformer-vocal-model/config_vocals_mel_band_roformer.yaml` 和 `MelBandRoformer.ckpt`，模型只输出精确 key `vocals`，`accompaniment` 由 `mixture - vocals` 生成；输出目录严格保留 `--source-root` 下的相对路径；支持 `--device cuda:0` 单卡、`--devices 0,1,...` 多卡 worker、父进程文件级聚合进度条、`--max-files` 扫描短路、按文件懒检查 pending/skipped 以避免大 manifest 启动前全量预扫、已完成条目跳过、默认 10 分钟以上音频 `skiplong` 跳过、旧 `metadata(status=error)` 超长重判并改写 `skiplong`、native 崩溃后按 `started` 当前文件标记 `worker_crash` 并重启 worker、异步 MP3 保存、`--chunk-batch-size` demix chunk batching，以及匹配源 mp3 直接复制为 `mixture.mp3`。
- `scripts/data_processing/`：面向实际数据处理任务的轻量入口。`separation_core.py` 是 OSS 分离 handler 使用的 RoFormer 核心模块，包含模型文件解析、`ffprobe/torchaudio` 时长预读、`torchaudio/ffmpeg` 音频加载、`.webm/.mp4` 容器抽音频、RoFormer 推理、44100 Hz stem 保存和 metadata 写入。`oss_prepare_separation.py` 是普通 `local_queue` handler，从 OSS 下载单条音频/视频到 worker 临时目录，默认大于等于 600 秒直接上传 `metadata(status=skiplong)` 并返回 `skiplong` receipt；短音频使用 worker 进程内缓存的 separator 生成 `mixture/vocals/accompaniment/metadata` 并上传到对应 OSS 输出目录，最后清理本地临时文件但保留模型。`oss_prepare_separation_pipeline.py` 使用同一 queue/state 格式，但在每张 GPU 内流水线化下载/预读、GPU 推理、MP3 保存和 OSS 上传，以提高 CPU/GPU 利用率。README 给出配置和运行示例。
- `scripts.data.datasets.PreparedSeparationDataset`：直接扫描 `prepare_separation.py` 产物目录并写入/读取 `index.list`，支持固定对外 `length`、用真实 `item_dirs` 取余读取，以及通过 `rebuild_index()` 重新扫描并替换 `self.item_dirs`；可用 `max_duration_seconds` 在单条 item 被选中后通过 `ffprobe` 按 `mixture.mp3` 容器时长 lazy 过滤长音频，按单任务或每 crop 任务列表只解码需要的 `mixture/vocals/accompaniment` stem 并集，供 `MosslandTaskDataset` 多任务训练使用；旧的包装式 separation stem dataset 已删除。
- `scripts.data.datasets.Musdb18HqSeparationDataset`：直接读取 MUSDB18-HQ 解压后的 `train/test/<track>/{mixture,vocals,drums,bass,other}.wav`，写入/读取 `index.list`，支持按任务只加载需要的 stem、多 crop、固定逻辑 `length` 和派生 `accompaniment=drums+bass+other`；供四轨分离训练配置使用。
- `scripts/tools/local_queue/`：共享文件系统本地任务队列工具包，提供 `TaskHandler/TaskRecord/TaskResult`、manifest bucket、lease、worker runner、monitor 和 finalize。核心一致性规则是任务可重复执行但只有当前 lease owner 能提交结果或记录失败；`write_manifest()` 不允许对已有 job 追加，避免重复 manifest。
- `scripts/tools/oss_tools/`：基于目录内 `bin/rclone` 和本机 `rclone.conf` 的 OSS 工具包，提供 `OssClient.upload_file()`、`download_file()`、`exists()`、`delete_file()` 和 `python -m scripts.tools.oss_tools.cli` 命令；`rclone.conf` 被 `.gitignore` 忽略，不应提交；代码注释里记录了 2026-06-12 对 `qz_oss2:public/zhaoguojie/Mossland/oss_tools_benchmark/` 小文件的实测耗时。
- `scripts/third_party/mel_band_roformer/`：从同事使用的 Mel-Band-Roformer-Vocal-Model 复制的最小模型实现，用于 `prepare_separation.py` 本地直推。
- `scripts/trainer_utils/`：Hydra/Lightning logger、callback 和通用训练工具。
- `tests/mossland_codec/`、`tests/test_prepare_separation.py`、`tests/test_separation_dataset.py`、`tests/test_local_queue.py`、`tests/test_oss_prepare_separation.py`：Mossland codec、任务适配、separation 预处理/读取、local queue 一致性和 OSS separation handler 的轻量单元测试。
- `docs/mossland-codec.md`：Mossland codec 架构、separation 预处理和数据集接法说明。
- `docs/`：持久项目记忆。
